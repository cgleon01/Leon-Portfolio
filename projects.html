My Projects

Here are some of the projects I've worked on:

  • Project 1: Vivid Auto Details website.

    In this website I have created a mostly just informational site for a car detailing business. It has several interacting tabs with two features in the website that have external functions. The Book now button takes you to an external Crm website in order to book and pay for an appointment. The submit a quote request form allows you to put the information of your vehicle and request a quote.

  • Project 2: Kaylies Portfolio website.

    This portfolio page is a fun interactive way to view the portfolio in a book format. It has tons of animations that help create that book reading experience.

  • Project 3: Dile Catalog.

    This old project was designed to be a catalog for a business that displays the products they sell. The Catalog was designed with features that help you filter out and search for certain products.
